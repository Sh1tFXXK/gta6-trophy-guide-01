Leonida Trophy Ledger: an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI. Every trophy is shown with its official name, description and grade, plus a guide written in our own words that names its sources, a three-step roadmap to the platinum, and a missable flag built from the official descriptions. The tracker is a checklist saved in the browser, with search, filters by kind (story, missable, collectibles, activities, online), a spoiler setting that hides story trophies until earned, and progress export and import. Static files only — no build step, no network, nothing leaves the browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. It also works with the network off: every file the page loads lives under app/.
